How this app works right now:

All CRUD operations are isolated inside the AcademicAPI service object in index.html. Currently, it persists data in localStorage so Faculty updates immediately reflect in the Student portal.

1 Required Supabase PostgreSQL Tables

users

id (uuid, PK), name (text), email (text), role ('faculty'|'student'), roll_no (text)

attendance

id (uuid, PK), student_id (FK), subject (text), date (date), status ('Present'|'Absent')

assignments

id (uuid, PK), subject (text), title (text), due_date (date), instructions (text)

submissions

id (uuid, PK), assignment_id (FK), student_id (FK), link_url (text), submitted_at (timestamptz)
